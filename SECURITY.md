# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public issue or pull request for them.

The preferred way is GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/internetarchive/openlibrary/security) of this repository.
2. Click **Report a vulnerability** and describe what you found.

If you can't use GitHub, email openlibrary@archive.org and cc: mek@archive.org.

Helpful details: the affected URL or file, steps to reproduce, and the impact you expect.

## Scope

This policy covers the code in this repository and openlibrary.org.

For other Internet Archive services, see the [Internet Archive's contact page](https://archive.org/about/contact/).

## Other questions

For questions or comments about Open Library that aren't security issues, email openlibrary@archive.org.
