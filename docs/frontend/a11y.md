## FocusableHostMixin

**File:** `openlibrary/components/lit/utils/focusable-host-mixin.js`

The primary a11y mechanism for Shadow DOM components. Solves two problems that arise when a custom element wraps a `<button>` in its shadow root:

1. `querySelectorAll('button, [tabindex]…')` on light DOM doesn't find shadow DOM buttons — the component is invisible to focus traps
2. `host.focus()` focuses the host element, not the inner button — `:focus-visible` fires on nothing

**What the mixin does:**
- Sets `tabindex="0"` on the host in `connectedCallback` (only if not already set)
- Uses `delegatesFocus: true` on the shadow root → `host.focus()` forwards to the first focusable inside shadow root; `:focus-visible` fires correctly on the inner element

**Usage:**
```javascript
import { FocusableHostMixin } from './utils/focusable-host-mixin.js';
export class OLChip extends FocusableHostMixin(LitElement) { ... }
```

**Overriding the focus target** (when the desired element isn't first in DOM order):
```javascript
get _focusTarget() {
    return this.shadowRoot?.querySelector('.my-button');
}
```

**Components using FocusableHostMixin:**
- `OLChip` — chip/tag interactive element
- `OlOptionsPopover` — popover trigger
- `OlToggle` — toggle switch
- `OlSelectPopover` — select dropdown trigger

## Hover Media Query Guard

Pattern used across Lit components to prevent hover styles from triggering on touch/mobile:

```css
@media (hover: hover) and (pointer: fine) {
    :host(:hover) .my-element { ... }
}
```

Found in: `OlPagination.js`, `OLChip.js`, `OLMarkdownEditor.js`, `OlOptionsPopover.js`, `OlSelectPopover.js`. This guards against the "sticky hover" issue on iOS Safari and Android where hover styles persist after touch.

## Reduced Motion Support

`prefers-reduced-motion` is handled in some components:

```css
@media (prefers-reduced-motion: reduce) {
    /* skip or simplify transitions */
}
```

Found in `OlOptionsPopover.js` (animation guard). `OlBanner.js` has a fallback for "no transition runs" with a comment: `// Fallback in case no transition runs (e.g. prefers-reduced-motion)`.

## iOS Safari Input Zoom

iOS Safari zooms the viewport when an `<input>` has `font-size < 16px`. The standard fix is ensuring all visible inputs use `font-size: 16px` minimum.

⚠️ UNVERIFIED — Whether OL has systematically addressed this across all form inputs is unknown within search budget. Check `openlibrary/plugins/worksearch/static/css/` and Jinja form templates. See cq #22.

## ARIA Usage

OL's Lit components use ARIA attributes directly in templates:

- `aria-label` — on interactive elements without visible text
- `aria-disabled="true"` — on disabled items in `OlPagination`
- `aria-current="page"` — on active page in pagination
- `aria-hidden="true"` — on decorative elements (`OlPagination` ellipsis `•••`)
- `aria-busy` — on `OLButton` during loading state
